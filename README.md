# Linguardia 

![Game preview](/Media/Solo.gif)


A multiplayer educational RPG made with Godot 4 where your combat power comes from your vocabulary.

## Purpose of this project: 

---

 This game is not trying to be a  full-scale competitive RPG. Instead, it focuses on combining language learning with real-time combat so that it can:
 - showcase Godot 4 capabilities for building multiplayer educational games
 - demonstrate WebSocket-based networking between Godot and a Node.js server
- provide an open-source reference for ATB (Active Time Battle) systems in Godot 4
- make vocabulary practice genuinely engaging through competitive gameplay

![Game preview](/Media/multiplayer.gif)



## Features: 
---
- ATB action bars  charge speed scales with typing accuracy and fluency
- attack damage and effects tied to translation correctness
- real-time PvP matches across multiple devices
- multiple language pair support via JSON word packs
- Node.js WebSocket server for match coordination
- simple and polished UI
- VFX on attacks and abilities


## Godot compatibility
---

### This project is compatible with Godot 4.6.

- support for Godot 4.7 is available on godot-4.7-support branch.
- support for Godot 4.7.1 is available on godot-4.7.1-support branch.
